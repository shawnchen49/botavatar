# Vendored Lucide icons

Original SVG files from `lucide-static@1.49.0`, copied without edits. Each catalog
entry records the upstream URL, version, SHA-256, and license path. The complete
upstream LICENSE preserves both Lucide ISC and inherited Feather MIT notices.

Use existing icons; do not redraw their paths. Rendering adapts color, stroke
weight, scale, and hat-specific placement. Source geometry stays in its original
24 by 24 viewBox; compilation normalizes its coordinate space to 256 by 256.
