# Soft Layered 2D parts

Production face, hair, hat, and fixed accessory SVG sources live here. Use a
shared 256 by 256 coordinate system and catalog-declared anchors. Renderer-owned
eye expressions remain in code; this profile does not support glasses.
Raster exploration is not a production source part. See
[asset authoring](../../../docs/asset-authoring.md) for the supported SVG format.
